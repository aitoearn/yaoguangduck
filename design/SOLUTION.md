# 方案设计

> 持续更新的活文档，反映当前最新方案；历史变更见 journal 和 git 记录。

> 原项目：Pollen Robotics Microduck（官方整机 $399）；本复刻为社区 kissqy 的飞特 HD1910 适配版。

## 1. 项目概述

复刻 MicroDuck 双足机器鸭（飞特版主线），目标：装出来 → 走起来 → 能训练自己的动作。
预算约 ¥3000（教程参考 2200～2500 + 工具/余量）。主线配置即社区已实机走过的路线，不自由发挥。

## 2. 总体架构

```
[蓝牙手柄]──蓝牙──> [机器人中控 R17 V167（PC，start.cmd）]
                          │ Wi-Fi / SSH
                          ▼
              [Radxa ZERO 3W（2G，TF卡启动，Public Image R1）]
                          │ 40pin 排针 GPIO/UART
                          ▼
              [kissqy 自制 HAT（成品，EH2.5/AMP2.0 口）]
                │ 总进电：NP-F550 7.4V 直供舵机总线（1000µF 电容+保险+开关）
                │ 5V 分电给 Zero（HAT 管，无需外置 UBEC）
                ▼
    [HD-1910 串口总线舵机 ×15] ←──半双工串口总线──> [imu_to_dxl IMU 板（总线 ID 200，FT6 固件）]
```

- **舵机**：HD-1910-C001 ×15（已团购下单）。全身 12 关节（每腿 3）+ 头颈/尾翼余量
- **主控**：Radxa ZERO 3W，2GB，无 eMMC → TF 卡跑系统；摄像头走排线
- **IMU**：一条总线 IMU 主线（`imu_to_dxl` RevA，挂舵机总线 ID 200）；BNO085 方案仅备选
- **电气保护**：总进电并 1000µF/16V 电容、串 5A 保险 + 船型开关（缺件清单已列）

## 3. 软件链路（版本对齐很重要）

| 组件 | 版本 | 作用 |
|---|---|---|
| 系统镜像 Public Image R1 | 官方 0.15.1 / control.40 预装 | 刷 TF 卡即可，免编译 |
| Zero 端固件 | **control.43**（FT6 适配） | 用 V167 中控随包升级 |
| IMU 固件 | FT6（STM32） | 成品板已烧，读到 ID 200 即验证通过 |
| 机器人中控 | R17 V167 | PC 端：标定、手柄操控、3D 姿态、固件维护 |
| 训练中控 | R1.5.27 | 训练任务、仿真评估、**ONNX 导出**（按需） |
| 运动模型 | V167 自带 10 份（6 常规 + 4 滑轮） | 不用手写舵机动作 |

**纪律：不装 fork、不改 IMU 配置、不混版本**（教程红线）。刷机用 Armbian Imager 自定义镜像直刷 `.img.xz`。

## 4. 关键选型（均已下单，详见 procurement/BOM.md）
