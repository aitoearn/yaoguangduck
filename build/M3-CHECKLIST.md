# M3 行动清单：刷机与单件验证（2026-11-02 启动）

> 前提：舵机未到不影响本阶段。目标：系统跑起来、IMU 验证通过、舵机写 ID 的流程演练完毕。
> 信息源：kissqy 仓库 README「三步开始」+ 复刻教程 4.2 节。红线：不装 fork、不改 IMU 配置、不混版本。

## 1. 开箱清点（30 分钟）

- [ ] 对照 procurement/BOM.md 逐项清点，缺件/破损拍照留证
- [ ] 摄像头：确认模组型号 IMX219、**检查附赠排线**（15P 1.0mm → 22P 0.5mm 同面，缺则补购约 ¥5）
- [ ] 万用表 UT136B+ 装电池、试表笔通断档（顺便验证表本身）
- [ ] 外壳：清点件数，拍照问店家是否含 TPU 软料件 + 电池仓打印件

## 2. 刷系统镜像（1 小时，不依赖其他任何东西）

- [ ] 下载镜像 R1：`microduck-zero3w-0.15.1-R1.img.xz`（kissqy releases 页）
- [ ] 下载 Armbian Imager（imager.armbian.com）
- [ ] TF 卡 #1 插读卡器 → Imager 选「自定义镜像」→ 选 .img.xz（**无需手动解压**）→ 写入
- [ ] 写完弹出，插入 ZERO 3W 卡槽

## 3. 首次开机 + 配网（30 分钟）

- [ ] ZERO 上电（此时可先用主控套装附带的电源线/USB 供电方式，不接 HAT 电池也能亮）
- [ ] 手机连热点 `Microduck-kissqy`（密码 `12345678`）
- [ ] 按提示设置家庭 Wi-Fi + 新系统密码；没弹页就访问 `http://10.42.0.1:8088`
- [ ] 记下分配的 IP，电脑 `ssh` 能登录即系统 OK → **journal 记录日期与现象**

## 4. 装中控 + 升固件（30 分钟）

- [ ] 下载 `Microduck-Console-R17-V167.zip`，解压后 PC 运行 `start.cmd`
- [ ] 连接鸭鸭（同一 Wi-Fi），确认中控能识别设备
- [ ] 在中控内升级随包固件 control.43（镜像预装的是 control.40）

## 5. IMU 单件验证（30 分钟）

- [ ] IMU 板接 HAT（注意接口版本间距要配对）
- [ ] 电池经 HAT 供电（或按仓库说明的验证方式），中控/日志里确认总线上出现 **ID 200**
- [ ] 读到 ID 200 = IMU 板 FT6 固件完好 ✅；读不到 → 查线序/供电，仍不行再考虑 ST-LINK 重刷

## 6. 为舵机到货做预演（可选，30 分钟）

- [ ] 调试板 FE-URT2-C001 接电脑，装飞特调试工具
- [ ] 手头有任何一颗旧舵机可先走一遍「写 ID / 读角度」流程，熟的操作
- [ ] 到货后流程：逐颗接调试板 → 写 ID（1~15）→ 记录中位 → 贴线号标签 → 入盒

## 本阶段纪律

- 带电不插拔舵机；舵机还带输出支架时不上电
- 出现异常发热/异味立刻断电
- 每完成一步在 journal/2026-11-02.md 追加记录（现象、IP、版本号）
